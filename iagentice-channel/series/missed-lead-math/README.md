# Missed-Lead Math (ClientFalcon)

~10 s kinetic-number motion graphic built with HyperFrames in this repo.
Pattern: "Miss 3 calls a week × $350 a job = $54,600 a year" — counter rolls up,
ends on the ClientFalcon mark. All numbers are labelled **example**; one industry
per video, using typical job values the viewer recognizes.

| Industry | Example inputs | Status |
|---|---|---|
| Plumber | 3 missed/week × $350 | idea |
| Dentist | 2 missed new patients/week × $900 first-year value | idea |
| Roofer | 1 missed lead/week × $8,000 | idea |
