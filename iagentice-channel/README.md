# iAgentice YouTube Channel

Planning home for the iAgentice channel: industry-targeted Shorts/Reels for
**ClientFalcon Voice** (AI receptionist) and **imknownas** (digital business cards).
Tagline: *Work that never sleeps.*

Everything here is planning and scripts. Rendered episodes are built in
`../videos/<nn>-<slug>/` with the shared sound kit `../videos/lib/cartoon_sfx.py`.
